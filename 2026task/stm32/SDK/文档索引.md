## 🔧 如何使用这些文档

### 典型开发流程

#### 1. 硬件配置阶段
- 查阅 **stm32f407vg.pdf** (Datasheet)
  - 确认引脚功能 (LQFP100 pinout)
  - 查看电气特性
  - 了解复用功能 (Alternate Functions)

#### 2. 外设寄存器级理解
- 查阅 **RM0090** (Reference Manual)
  - 深入理解外设工作原理
  - 查看寄存器位定义
  - 了解配置流程

#### 3. HAL库开发
- 查阅 **UM1725** (HAL手册) 或 **STM32F407_HAL_API_Manual.chm**
  - 查找需要的HAL函数
  - 了解函数参数和返回值
  - 查看使用示例

#### 4. RTOS开发
- 查阅 **CMSIS-RTOS2在线文档** 或 **CMSIS_RTOS_Tutorial.pdf**
  - 创建任务: `osThreadNew()`
  - 使用信号量: `osSemaphoreNew()`, `osSemaphoreAcquire()`
  - 使用消息队列: `osMessageQueueNew()`, `osMessageQueuePut()`
  - 查看 `CMSIS_RTOS_V2/cmsis_os2.h` 了解API定义

#### 5. 参考示例代码
- 浏览 STM32CubeF4 固件包中的示例
  - 外设示例: `Projects/STM32xxx/Examples/`
  - FreeRTOS示例: `Projects/STM32xxx/Applications/FreeRTOS/`

### 快速查找技巧

#### 查找GPIO配置
1. **RM0090** → 第6章 → GPIO寄存器
2. **UM1725** → 搜索 "HAL_GPIO" → 查看API

#### 查找定时器配置
1. **RM0090** → 第14章 (TIM1/TIM8 高级定时器) 或 第18章 (通用定时器)
2. **UM1725** → 搜索 "HAL_TIM" → 查看API

#### 查找UART配置
1. **RM0090** → 第24章 → USART
2. **UM1725** → 搜索 "HAL_UART" → 查看API

#### 查找FreeRTOS API
1. **CMSIS-RTOS2在线文档** → 搜索具体函数
2. 或查看 `CMSIS_RTOS_V2/cmsis_os2.h` 头文件
