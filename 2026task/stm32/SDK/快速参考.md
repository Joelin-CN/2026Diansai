## 🌐 重要在线资源

### CMSIS-RTOS2 API参考（推荐）
```
https://arm-software.github.io/CMSIS_5/RTOS2/html/index.html
```
**常用API**:
- `osThreadNew()` - 创建任务
- `osDelay()` - 延时
- `osMutexNew()`, `osMutexAcquire()`, `osMutexRelease()` - 互斥锁
- `osSemaphoreNew()`, `osSemaphoreAcquire()`, `osSemaphoreRelease()` - 信号量
- `osMessageQueueNew()`, `osMessageQueuePut()`, `osMessageQueueGet()` - 消息队列

### FreeRTOS官方书籍（免费）
```
https://www.freertos.org/fr-content-src/uploads/2018/07/161204_Mastering_the_FreeRTOS_Real_Time_Kernel-A_Hands-On_Tutorial_Guide.pdf
```

## 💡 使用建议

### CHM文件打开问题
如果 `STM32F407_HAL_API_Manual.chm` 显示"无法显示此页":
1. 右键CHM文件 → 属性
2. 点击"解除锁定"按钮
3. 确定后重新打开

### 阅读优先级

**新手必读**:
1. stm32f407vg.pdf - 了解芯片引脚
2. STM32CubeF4_Getting_Started.pdf - 了解开发环境
3. CMSIS_RTOS_Tutorial.pdf - 学习RTOS基础

**日常开发最常用**:
1. RM0090 (参考手册) - 理解外设原理
2. STM32F407_HAL_API_Manual.chm - 查找HAL函数
3. CMSIS-RTOS2在线文档 - 查找RTOS API

## 📖 推荐学习路径

### 第1步：熟悉芯片
- 阅读 **stm32f407vg.pdf** 第4章：引脚定义
- 了解LQFP100封装的引脚功能

### 第2步：点亮LED（GPIO）
- 参考 `Projects/STM32F407VG-Discovery/Examples/GPIO/`
- 查阅 RM0090 第6章和 UM1725 HAL_GPIO部分

### 第3步：串口通信（UART）
- 参考 `Projects/STM32F407VG-Discovery/Examples/UART/`
- 查阅 RM0090 第24章和 UM1725 HAL_UART部分

### 第4步：定时器和中断
- 参考 `Projects/STM32F407VG-Discovery/Examples/TIM/`
- 查阅 RM0090 定时器章节

### 第5步：引入FreeRTOS
- 阅读 **CMSIS_RTOS_Tutorial.pdf**
- 参考 `Projects/STM32F407VG-Discovery/Applications/FreeRTOS/`
- 学习任务创建、信号量、消息队列

### 第6步：高级外设
- ADC、SPI、I2C等
- 参考固件包中的示例代码
