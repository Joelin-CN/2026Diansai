## 🚀 快速开始

### 如何运行校准工具

在你的主程序中调用：

```c
#include "app/calibration_tool.h"

// 在main()或某个任务中调用
CalibrationTool_Run();
```

或者单独运行某个校准：

```c
#include "app/encoder_resolution_calibration.h"
#include "app/ir_sensor_calibration.h"
#include "app/motor_direction_calibration.h"

// 只运行编码器校准
EncoderResolutionCalibration_Run();

// 只运行IR传感器校准
IrSensorCalibration_Run();

// 只运行电机方向校准
MotorDirectionCalibration_Run();
```

## 📋 校准优先级

### 🔴 优先级1：编码器分辨率（必须先做）
**为什么最重要？**
- 错误配置会导致速度估计错误 4.67 倍
- 影响所有运动控制功能
- 无法循迹、无法跟踪轨迹

**如何校准？**
1. 运行 `EncoderResolutionCalibration_Run()`
2. 手动旋转左轮完整1圈
3. 记录计数值
4. 重复右轮
5. 验证是否约等于 1560 ± 5%

**预期结果：**
- 左轮：1560 ± 78 counts
- 右轮：1560 ± 78 counts

**如果失败：**
```c
// 更新配置文件使用实测值
// motion_config.h:44
#define ENCODER_PPR <实测值>

// config.c:35
.pulses_per_revolution = <实测值>U
```

---

### 🟡 优先级2：IR传感器符号（第二重要）
**为什么重要？**
- 符号错误会导致循迹反向
- 小车会越跑越偏

**如何校准？**
1. 运行 `IrSensorCalibration_Run()`
2. 将小车放在黑线上
3. 手动向右移动，观察 lateral_error
4. 手动向左移动，观察 lateral_error

**预期结果：**
- 向右偏 → lateral_error < 0 (负值)
- 向左偏 → lateral_error > 0 (正值)

**如果失败：**
```c
// config.c:18-23
// 将 ir_weights[] 所有值取反
static const float ir_weights[8] = {
    -3.9861f,  // 改为负
    -2.8472f,
    -1.7083f,
    -0.5694f,
    +0.5694f,  // 改为正
    +1.7083f,
    +2.8472f,
    +3.9861f
};
```

---

### 🟢 优先级3：电机方向（可选）
**为什么做？**
- 验证电机接线是否正确
- 避免混淆的调试

**如何校准？**
1. 运行 `MotorDirectionCalibration_Run()`
2. 自动测试6种情况
3. 观察结果

**预期结果：**
- 正转 → 编码器增加
- 反转 → 编码器减少

**如果失败：**
- 选项1：交换电机接线（推荐）
- 选项2：软件配置取反

## 🔧 常见问题

### Q1: 编码器计数为0怎么办？
**可能原因：**
- 编码器线未连接
- TIM未配置为编码器模式
- 编码器供电问题

**解决方法：**
1. 检查硬件连接
2. 检查 TIM3/TIM4 配置
3. 用万用表测试编码器输出

---

### Q2: 编码器计数值与1560差很多？
**可能原因：**
- 减速比不是30:1
- 编码器线数不是13 PPR
- 编码器在减速后的轮轴上

**解决方法：**
1. 使用实测值更新配置
2. 重新确认硬件参数
3. 多次测量取平均值

---

### Q3: IR传感器全是0或全是4095？
**可能原因：**
- UART通信失败
- 传感器供电问题
- 传感器距离不合适

**解决方法：**
1. 检查UART连接
2. 检查传感器供电（VCC/GND）
3. 调整传感器高度（2-5mm）

---

### Q4: lateral_error符号反了？
**原因：**
- IR权重数组符号配置错误

**解决方法：**
```c
// 在 config.c 中将所有权重取反
// 从: {3.9861, 2.8472, ...}
// 改为: {-3.9861, -2.8472, ...}
```

---

### Q5: 电机方向反了？
**解决方法（二选一）：**

**方法1：硬件修改（推荐）**
```
交换对应电机的两根接线
```

**方法2：软件修改**
```c
// config.c
static const int8_t encoder_directions[2] = {
    -1,  // 左轮取反
     1   // 右轮正常
};
```
