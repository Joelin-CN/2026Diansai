- 原地旋转所需的轮速差增加

## 权重计算详解

### 坐标系约定

**代码坐标系** (车辆坐标系):
- **X轴**: 前方为正 (+X = 前方)
- **Y轴**: 左侧为正 (+Y = 左侧)
- **Z轴**: 上方为正 (+Z = 上方)

### 权重公式

对于IR传感器阵列，横向位置权重用于计算加权质心（lateral error）:

```
weight[i] = Y_position[i] / 10mm
```

其中:
- `Y_position[i]`: 传感器i在代码坐标系中的Y坐标 (mm)
- 除以10mm是归一化因子，使权重数值适中

### 新权重推导

| 通道 | Y坐标 (mm) | 计算 | 权重 |
|------|------------|------|------|
| 0 | +39.8606 | 39.8606/10 | **+3.9861** |
| 1 | +28.4719 | 28.4719/10 | **+2.8472** |
| 2 | +17.0831 | 17.0831/10 | **+1.7083** |
| 3 | +5.6944 | 5.6944/10 | **+0.5694** |
| 4 | -5.6944 | -5.6944/10 | **-0.5694** |
| 5 | -17.0831 | -17.0831/10 | **-1.7083** |
| 6 | -28.4719 | -28.4719/10 | **-2.8472** |
| 7 | -39.8606 | -39.8606/10 | **-3.9861** |

### 加权质心计算

```c
float weighted_sum = 0.0f;
float total_weight = 0.0f;

for (int i = 0; i < 8; i++) {
    float normalized = sensor_value[i] / max_value;
    weighted_sum += normalized * ir_weights[i];
    total_weight += normalized;
}

float lateral_error = weighted_sum / total_weight;
```

**符号约定**:
- `lateral_error > 0`: 黑线在车辆左侧（车偏右）→ 需要向左转
- `lateral_error < 0`: 黑线在车辆右侧（车偏左）→ 需要向右转
- `lateral_error = 0`: 黑线在车辆中心 → 保持直行

## 影响分析

### 1. 运动学模型

**差速底盘运动学**:
```
v = (v_left + v_right) / 2
ω = (v_right - v_left) / wheel_track
```

轮距增大86.1%后:
- 相同的轮速差产生的角速度**减小**为原来的53.7% (115/214)
- 转向响应变慢，需要更大的轮速差来实现相同的转向角速度
- PID控制器可能需要重新调参（增大Kp）

### 2. EKF位置估计

IR阵列向前移动50.9mm后:
- 测量更新的空间偏移量增加
- 状态转移矩阵中的杠杆臂效应增强
- 建议重新进行EKF协方差矩阵标定

### 3. 循迹性能

**优点**:
- 前瞻距离增加38.5%，转弯预判能力增强
- 高速循迹稳定性提高

**需要注意**:
- 转向响应变慢（轮距增大）
- 可能需要增大转向PID的比例系数
- 急转弯时可能需要提前减速

### 4. 标定需求

| 项目 | 优先级 | 预计时间 | 方法 |
|------|--------|----------|------|
| 轮距验证 | **P0** | 15分钟 | 原地旋转法 |
| IR权重符号验证 | **P0** | 10分钟 | 手动推车测试 |
| 转向PID调参 | **P1** | 30分钟 | 实车循迹测试 |
| EKF协方差重标定 | **P2** | 1小时 | 直线+转弯数据采集 |
| 前瞻增益调整 | **P2** | 20分钟 | 不同速度循迹测试 |

## 验证步骤

### 步骤1: 轮距验证（原地旋转法）

**目标**: 验证新轮距214mm是否准确

**步骤**:
1. 将小车放置在平坦地面
2. 标记初始航向角
3. 发送旋转命令：原地旋转10圈 (3600度)
4. 测量实际旋转角度
5. 计算: `实际轮距 = 理论轮距 × (实际角度 / 3600°)`
6. 验证误差 < 5%

**预期结果**: 实际轮距 = 214 ± 10.7 mm

### 步骤2: IR权重符号验证

**目标**: 验证新权重符号是否正确

**步骤**:
1. 将小车放置在黑线上（线居中）
2. 启动IR传感器校准工具
3. 手动向右推小车 → 观察`lateral_error`符号
4. 手动向左推小车 → 观察`lateral_error`符号

**预期结果**:
- 向右推 → `lateral_error < 0` (黑线在右侧)
- 向左推 → `lateral_error > 0` (黑线在左侧)

**如果符号相反**:
```c
// 将config.c中的ir_weights数组所有值取反
static const float ir_weights[8] = {
    -3.9861f, -2.8472f, -1.7083f, -0.5694f,
    0.5694f, 1.7083f, 2.8472f, 3.9861f
};
```

### 步骤3: 循迹测试

**目标**: 验证新参数下的循迹性能

**测试场景**:
1. 直线循迹 (0.3 m/s)
2. 缓弯循迹 (0.3 m/s, R > 0.5m)
3. 急弯循迹 (0.2 m/s, R ≈ 0.3m)

**观察指标**:
- 横向偏差范围
- 转向响应速度
- 是否出现振荡
- 能否稳定通过急弯

### 步骤4: PID调参（如需要）

如果转向响应过慢，增大转向PID的比例系数:

```c
// motion_control.c
// 原值
pid_params.kp = 2.0f;

// 建议新值（轮距增大86% → Kp增大约86%）
pid_params.kp = 3.7f;  // 2.0 × 1.86
```

## 注意事项

### ⚠️ 关键警告

1. **轮距一致性**: `motion_config.h::WHEEL_BASE` 和 `config.c::wheel_track_m` 必须始终保持一致
2. **权重符号**: IR权重符号错误会导致循迹反向（越跑越偏），**必须通过实车验证**
3. **坐标系约定**: 所有参数均基于代码坐标系 (X=前, Y=左, Z=上)
4. **测量精度**: 轮距测量误差 > 5% 会显著影响转向精度
5. **标定顺序**: 必须先验证轮距，再调试循迹PID
