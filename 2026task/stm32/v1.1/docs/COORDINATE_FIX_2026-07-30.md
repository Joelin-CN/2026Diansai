## 问题详情

### 问题1: IR传感器通道位置假设错误

**错误假设** (多个文档):
- 通道0 = 最右侧
- 通道7 = 最左侧

**实际硬件布局** (用户确认):
- 通道0 = 最左侧
- 通道7 = 最右侧

**影响**: 所有基于错误假设的权重数组注释都是错误的。

### 问题2: 权重数组代码正确，但注释错误

**代码中的权重数组** (`config.c:78-80`):
```c
static const float ir_weights[SD_IR_CHANNEL_COUNT] = {
    3.9861f, 2.8472f, 1.7083f, 0.5694f,     // 通道0-3
    -0.5694f, -1.7083f, -2.8472f, -3.9861f  // 通道4-7
};
```

**这个权重数组是正确的！** 因为：
- 通道0（左侧）= +3.9861（最大正值）→ 符合代码坐标系 +Y=左侧
- 通道7（右侧）= -3.9861（最大负值）→ 符合代码坐标系 -Y=右侧

但注释错误地标注为"通道0=右侧"。

### 问题3: 文档中记录的权重数组错误

**API_PITFALLS_GUIDE.md** (修复前):
```c
static const float ir_weights[8] = {
    -0.5694f, -1.7083f, -2.8472f, -3.9861f,  // 右侧（负权重）
    +0.5694f, +1.7083f, +2.8472f, +3.9861f   // 左侧（正权重）
};
```

这与代码中的实际权重数组符号**完全相反**！

## 正确的坐标系约定

### 代码坐标系定义
| 轴 | 方向 | 正方向 |
|----|------|--------|
| X | 车辆前后 | 前方为正 |
| Y | 车辆左右 | **左侧为正** |
| Z | 车辆上下 | 上方为正 |

### IR传感器阵列（实际硬件布局）
| 通道 | 物理位置 | Y坐标（代码坐标系） | 权重值 |
|------|----------|-------------------|--------|

| 1 | | +28.4719 mm | +2.8472 |
| 2 | | +17.0831 mm | +1.7083 |
| 3 | | +5.6944 mm | +0.5694 |
| 4 | | -5.6944 mm | -0.5694 |
| 5 | | -17.0831 mm | -1.7083 |
| 6 | | -28.4719 mm | -2.8472 |
| 7 | 最右侧 | -39.8606 mm | -3.9861 |

### lateral_error 符号约定（统一定义）

| 车辆状态 | 黑线位置 | lateral_error | 修正方向 |
|----------|----------|---------------|----------|
| 车偏右 | 线在左侧传感器（通道0-3） | **> 0** | 向左转 |
| 车偏左 | 线在右侧传感器（通道4-7） | **< 0** | 向右转 |
| 居中 | 线在中间 | **≈ 0** | 直行 |

**计算公式**:
```c
lateral_error = Σ(weight[i] × black_strength[i]) / Σ(black_strength[i])
```

**推导逻辑**:
- 通道0（左侧）权重 = +3.9861（正值）
- 车偏右 → 黑线在左侧 → 左侧传感器检测到高强度
- 正权重 × 高强度 → lateral_error > 0（正值）
- 控制器响应：steering = -Kp × lateral_error → 负转向 → 向左修正 ✓

## 验证方法

本次修复基于以下逻辑推导（用户未进行实车测试）：

1. **硬件布局确认**: 用户明确通道0=左侧，通道7=右侧
2. **代码坐标系**: +Y=左侧（已明确定义）
3. **权重数组**: 通道0（左侧）=+3.9861（工作目录中的值）
4. **加权质心算法**: 正权重×高强度 → 正结果
5. **控制逻辑**: 负反馈控制（steering = -Kp × error）

### 推导验证

**场景A: 车偏右**
- 黑线在车辆左侧 → 左侧传感器（通道0-3）检测到
- weight[0-3] = +3.99, +2.85, +1.71, +0.57（正值）
- lateral_error = Σ(正权重 × 高强度) / Σ(强度) = **正值**
- 控制响应: steering = -Kp × (+) = 负值 → **向左转修正** ✓

**场景B: 车偏左**
- 黑线在车辆右侧 → 右侧传感器（通道4-7）检测到
- weight[4-7] = -0.57, -1.71, -2.85, -3.99（负值）
- lateral_error = Σ(负权重 × 高强度) / Σ(强度) = **负值**
- 控制响应: steering = -Kp × (-) = 正值 → **向右转修正** ✓

### 实车测试建议

**强烈建议**进行实车测试最终验证：
1. 将小车放在黑线上，串口输出 lateral_error
2. 手动向右推偏（黑线出现在左侧传感器）
3. 观察 lateral_error 应为**正值**（如果是负值，权重需要全部取反）
4. 手动向左推偏（黑线出现在右侧传感器）
5. 观察 lateral_error 应为**负值**
