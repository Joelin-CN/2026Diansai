# IR校准阈值优化报告

**日期**: 2026-07-30  
**版本**: v1.2.2  
**问题**: 反向传感器阈值设置不当，导致误判

---

## 问题发现

实车测试显示：**激活通道数=6，触发路口检测（CROSS）**

```
[0] 264 283 288 1043 1232 326 273 256 | A:6 E:+0.00 CROSS
```

**分析**：
- 预期激活：Ch3,4（黑线上）→ A:2
- 实际激活：Ch0,1,2,3,4,5 → A:6
- 原因：阈值512.7太低，白色区域也被误判

---

## 根本原因

**阈值计算错误** - 对反向传感器使用了60%

### 反向传感器工作原理
```
white_reference = 1136 (黑色基准)
Threshold = 512.7 (60%)

强度计算: strength = 1136 - raw

白色区域 (raw ~280):
  strength = 1136 - 280 = 856 > 512.7 ✓ 激活（错误！）

黑色区域 (raw ~1136):
  strength = 1136 - 1136 = 0 < 512.7 ✗ 未激活（正确）
```

**问题**：阈值应该更高，才能避免白色区域误判！

---

## 解决方案

### 调整阈值比例

**修改前**：
```c
// 反向传感器使用60%（错误）
threshold = black_strength * 0.6f;  // 854 * 0.6 = 512
```

**修改后**：
```c
// 反向传感器使用50%（正确）
threshold = black_strength * 0.5f;  // 854 * 0.5 = 427
```

### 为什么50%是正确的？

对于反向传感器：
- 黑色强度范围：0 ~ 100（在黑线上）
- 白色强度范围：800 ~ 900（远离黑线）
- **阈值应该接近黑色的上限，而不是中间**

```
Black: 0 -------- 100
              ↑ Threshold = 427
White:                         800 -------- 900
```

设置为427后：
- 黑色区域 (strength 0~100) < 427 ✓ 激活
- 白色区域 (strength 800~900) > 427 ✗ 不激活

## 技术要点

### 正向 vs 反向传感器的阈值策略

| 传感器类型 | 白色强度 | 黑色强度 | 阈值策略 | 比例 |
|-----------|---------|---------|---------|------|
| **正向** | 高 | 低 | 取60%（偏向白色） | 0.6 |
| **反向** | 高 | 低 | 取50%（偏向黑色） | 0.5 |

### 为什么不同？

**正向传感器**（white > black）：
- 阈值偏向白色（60%），宽容黑线检测
- 防止黑线丢失

**反向传感器**（black > white）：
- 阈值偏向黑色（50%），严格黑线检测
- 防止白色误判为黑线

## 后续优化（可选）

如果50%仍不理想，可以考虑：

1. **动态阈值**
   - 根据实时最大/最小强度调整
   - 适应光照变化

2. **自适应比例**
   - 正向：0.5 ~ 0.7
   - 反向：0.3 ~ 0.5
   - 根据对比度自动选择

3. **双阈值策略**
   - 高阈值：确定在黑线上
   - 低阈值：可能接近黑线
   - 状态机平滑切换
