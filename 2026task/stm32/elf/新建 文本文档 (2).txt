下面是当前“低速循迹版”的完整运行流程。它是调试版，最大 PWM 25%，不满足20秒一圈的正式比赛速度要求。

### 1. 使用固件

烧录：

[STM32F407_Task2_v1_1_LOW_SPEED_TEST.elf](C:/Users/35336/Desktop/diansai/v1.1/firmware/STM32F407_Task2_v1_1_LOW_SPEED_TEST.elf)

当前接线：

- ICM42688：
  - PB13 → SCK
  - PB14 → MISO/SDO
  - PB15 → MOSI/SDA
  - PE7 → CS
  - 3V3、GND
- B电机＝左轮
- C电机＝右轮
- 循迹模块使用 USART2、115200 baud

### 2. 上电初始化

固件依次执行：

1. 电机初始化并立即停止。
2. 编码器初始化。
3. 循迹模块初始化，并请求模拟量模式。
4. 初始化配置和微秒计时器。
5. 初始化 ICM42688。
6. 读取 `WHO_AM_I`，正常应为：

```text
WHO_AM_I value: 0x47
```

7. 静止采集100帧进行陀螺仪零偏标定，约1秒。这期间不要动车。
8. 初始化传感器预处理、循迹感知和运动控制器。
9. 进入待启动状态。

正常应该看到：

```text
ICM42688 WHO_AM_I check: OK
IMU: available
Init Complete
```

### 3. 启动方式

当前低速版不是按键启动，而是自动启动：

- 小车放到黑线上；
- 连续收到3帧有效循迹数据；
- 50Hz决策周期下约60ms；
- 自动进入题2绕圈状态。

串口显示：

```text
Line detected, starting Task 2 lap...
```

如果需要“按下按键后才启动”，还需要单独把按键状态接入 `PT_IDLE`，当前版本没有做这个门控。

### 4. 控制循环频率

主循环为500Hz：

- 500Hz：读取左右编码器。
- 100Hz：轮速PI、IMU角速度反馈和PWM计算。
- 50Hz：读取循迹、计算偏差、判断赛道区段及任务状态。

### 5. 循迹计算逻辑

循迹模块使用模拟量计算：

- `lateral_error`：黑线左右位置误差。
- `heading_error`：黑线移动趋势/航向误差。
- `active_mask`：当前检测到黑线的通道。
- `active_count`：激活通道数量。

方向定义：

- 黑线在车体左侧 → `lateral_error > 0`
- 黑线在车体右侧 → `lateral_error < 0`
- `omega > 0` → 向左修正
- `omega < 0` → 向右修正

转向指令：

```text
omega = 弯道前馈
      + Kp × lateral_error
      + Kd × heading_error
```

宽黑线同时覆盖中间四路是允许的，算法使用多路加权位置，不要求始终只有中间两路激活。

### 6. 低速参数

直道：

```text
目标速度：0.15 m/s
Kp：0.35
Kd：0.08
最大角速度：0.35 rad/s
```

弯道：

```text
目标速度：0.10 m/s
Kp：0.45
Kd：0.10
最大角速度：0.45 rad/s
```

终点接近阶段：

```text
目标速度：0.08 m/s
Kp：0.40
Kd：0.08
最大角速度：0.35 rad/s
```

PWM硬限制：

```text
左轮：0～25%
右轮：0～25%
```

只允许车轮正转，修正时内侧轮可以降到0，但不会反转，避免出现原来左右轮突然反转和原地转向的情况。

### 7. IMU的作用

循迹传感器负责外环，计算目标角速度 `omega`。

ICM42688提供实际Z轴角速度，进入内环：

```text
yaw_error = omega_target - gyro_z
```

最终差速转向量：

```text
turnPWM = 20 × omega_target
        + 3 × yaw_error
```

也就是说：

- 循迹决定应该往哪个方向转、转多快；
- IMU检测小车实际上转了多快；
- 两者结合生成左右轮PWM差。

IMU数据异常时会自动关闭IMU反馈，仅保留转向前馈，不会把全零数据当作有效陀螺仪数据。

### 8. 赛道分段

根据编码器累计距离和循迹传感器前置183mm的距离进行提前判断：

- A→B直道：0～1.5m
- B→C半圆：1.5～3.071m
- C→D直道：3.071～4.571m
- D→A半圆：4.571m之后
- 5.0m后进入低速接近终点阶段

两个半圆按顺时针方向运行，弯道会加入：

```text
omega_feedforward = -速度 / 0.5m
```

循迹误差只负责在这个基础上继续修正。

### 9. 终点判断

累计距离超过5.5m后才允许识别A点横线，避免把宽黑线误认为终点。

满足以下条件才确认终点：

- 至少6路传感器同时检测到黑线；
- 连续确认3帧，即约60ms。

确认后：

1. 目标速度设置为0；
2. 由运动控制器减速；
3. 左右轮平均速度低于0.05m/s；
4. 彻底关闭电机，任务完成。

### 10. 丢线保护

短暂丢线时：

- 保存最后一次有效偏差方向；
- 继续向最后看到黑线的一侧修正；
- 前进速度降低到当前区段速度的55%。

连续丢线20帧，即约400ms后：

```text
进入 PT_FAULT
停止运动控制
关闭左右电机
```

### 11. 串口数据怎么看

每秒输出一次：

```text
state
dist
line
mask
act
err
hdg
cmdV
omega
lost
vL vR
pwmL pwmR
imuInit
imuFrame
gyroZ
yawErr
turnPWM
```

重点确认：

```text
imuInit=1
imuFrame=1
```

以及：

- 黑线向左移动时 `err` 应变为正；
- 黑线向右移动时 `err` 应变为负；
- `err>0` 时通常应有 `pwmR>pwmL`；
- `err<0` 时通常应有 `pwmL>pwmR`。
