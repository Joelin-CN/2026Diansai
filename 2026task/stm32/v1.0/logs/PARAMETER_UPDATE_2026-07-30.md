   - 文件: `modules/Sens-Decision/src/state_evaluate.c`

2. **轨迹生成器 (TrajectoryGenerator)**
   - Pure Pursuit算法中的坐标计算
   - 文件: `modules/Sens-Decision/src/trajectory_generate.c`

3. **路径定义 (SquarePath)**
   - 方形路径的路点坐标

### 建议处理方式

**方案1: 修改所有代码以匹配新坐标系**（工作量大）

**方案2: 在配置层做坐标转换**（推荐）
```c

// 物理坐标: 前(+Y), 右(+X)
// 代码坐标: 前(+X), 左(+Y)

// code_x = physical_y
// code_y = -physical_x
```

**方案3: 确认代码实际使用的坐标系**
- 检查 `state_evaluate.c` 中 EKF 的运动模型
- 检查 `square_path.c` 中路径点的定义
- 如果代码已经是前(+Y)，则无需修改

## ⚡ 重要提醒

### 编码器配置错误的影响：

如果编码器PPR配置错误，会导致：
- ❌ 速度估计错误（最严重）
- ❌ 位置估计错误
- ❌ PID控制失效
- ❌ 轨迹跟踪失败
- ❌ 小车可能完全无法循迹

**所以请务必先确认编码器的实际分辨率！**
