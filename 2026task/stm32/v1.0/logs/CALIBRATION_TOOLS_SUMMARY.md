## 🎯 校准工具功能

### 编码器分辨率校准

**目的**: 验证配置值 ENCODER_PPR = 1560 是否准确

**方法**:
1. 复位编码器计数
2. 提示用户手动旋转左轮完整1圈
3. 测量编码器计数变化
4. 对比预期值1560
5. 重复右轮测试

**输出**:
- 实测计数值
- 偏差百分比
- 通过/失败判断
- 修正建议（如果需要）

**预期时长**: 5分钟

---

### IR传感器符号验证

**目的**: 验证lateral_error的符号是否正确

**方法**:
1. 显示传感器原始值
2. 计算加权平均得到lateral_error
3. 提示用户移动小车
4. 实时显示lateral_error变化
5. 验证符号是否正确

**预期行为**:
- 小车向右偏 → lateral_error < 0 (负值)
- 小车向左偏 → lateral_error > 0 (正值)

**输出**:
- 实时传感器值
- lateral_error符号
- 通过/失败判断
- 修正建议（如权重取反）

**预期时长**: 3分钟

---

### 电机方向校准

**目的**: 验证电机正反转和编码器方向是否一致

**方法**:
1. 以20% PWM测试左电机正转/反转
2. 以20% PWM测试右电机正转/反转
3. 测试双电机同时运动
4. 检查编码器计数变化方向

**预期行为**:
- 正转 → 编码器增加
- 反转 → 编码器减少

**输出**:
- 各测试的编码器变化量
- 方向判断（正确/反转）
- 修正建议（接线或软件配置）

**预期时长**: 2分钟

## 🚀 如何使用

### 快速开始（3步）

#### 第1步: 添加到构建系统

在你的项目构建配置中添加新文件：

```makefile
# 如果使用Makefile
C_SOURCES += \
Core/Src/app/calibration_tool.c \
Core/Src/app/encoder_resolution_calibration.c \
Core/Src/app/ir_sensor_calibration.c
```

或者在IDE中将这些文件添加到项目。

#### 第2步: 在主程序中调用

```c
#include "app/calibration_tool.h"

int main(void) {
    // ... 初始化代码 ...
    
    // 运行校准工具
    CalibrationTool_Run();
    
    // ... 继续正常程序 ...
}
```

#### 第3步: 编译、下载、运行

```bash
# 编译
make

# 下载到STM32
# (使用你的下载工具，如st-flash, openocd等)

# 打开串口终端观察输出
# 波特率: 115200
```

### 执行校准（10分钟）

#### 🔴 编码器分辨率校准（5分钟）

```
1. 运行程序，进入校准工具
2. 选择 [1] 编码器分辨率校准
3. 按提示操作：
   - 在左轮上做标记
   - 手动旋转完整1圈
   - 等待30秒倒计时
   - 记录结果
4. 重复右轮测试
5. 判断是否通过（偏差<5%）
```

**通过标准**: 1560 ± 78 counts (±5%)

#### 🟡 IR传感器符号验证（3分钟）

```
1. 选择 [2] IR传感器符号验证
2. 将小车放在黑线上
3. 观察传感器原始值
4. 手动向右移动小车
   - 观察lateral_error是否变负
5. 手动向左移动小车
   - 观察lateral_error是否变正
6. 判断符号是否正确
```

**通过标准**: 右偏负值，左偏正值

#### 🟢 电机方向校准（2分钟）

```
1. 选择 [3] 电机方向校准
2. 自动测试6种情况
3. 观察串口输出
4. 检查所有测试是否通过
```

**通过标准**: 正转增加，反转减少
