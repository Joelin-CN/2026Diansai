---

## 🔴 关键问题：RXNEIE未设置

虽然代码中有：
```c
__HAL_UART_ENABLE_IT(IR_UART_HANDLE, UART_IT_RXNE);
```

但实际CR1寄存器中**没有RXNEIE标志**，这意味着：
- 即使传感器返回数据，UART4也不会触发中断
- `UART4_IRQHandler` 永远不会被调用
- 接收的数据会丢失

**这是一个严重的软件Bug，必须先修复！**

---

## 🛠️ 修复步骤

### Step 1: 修复RXNEIE未设置问题

修改 `modules/IR-tracker/src/ir_uart_sensor.c:69-79`：

```c
void IrUartSensor_Init(void)
{
    IrUartSensor_Reset();

    // Enable UART receive interrupt
    __HAL_UART_ENABLE_IT(IR_UART_HANDLE, UART_IT_RXNE);

    // Set interrupt priority and enable
    HAL_NVIC_SetPriority(IR_UART_IRQn, 5, 0);
    HAL_NVIC_EnableIRQ(IR_UART_IRQn);

    // WORKAROUND: Force enable RXNEIE by directly setting CR1 register
    // (Some HAL versions have bugs with __HAL_UART_ENABLE_IT macro)
    SET_BIT(huart4.Instance->CR1, USART_CR1_RXNEIE);
    
    // Verify it's set
    if (!(huart4.Instance->CR1 & USART_CR1_RXNEIE)) {
        // ERROR: Still not set!
        printf("[ERROR] Failed to enable UART4 RXNEIE!\r\n");
    } else {
        printf("[OK] UART4 RXNEIE enabled (CR1=0x%08lX)\r\n", huart4.Instance->CR1);
    }
}
```

### Step 2: 重新编译和测试

1. 编译新版本
2. 烧录
3. 查看串口输出是否显示 `[OK] UART4 RXNEIE enabled`
4. 再次运行诊断，检查CR1是否包含 `[RXNEIE=ON]`

## 🧪 简易测试方法（无示波器）

### 测试1：回环测试

**目的**：验证STM32的UART4发送和接收是否正常

**步骤**：
1. 物理短接 PC10 和 PC11（用杜邦线）
2. 重新上电，运行诊断
3. 查看是否显示 `RX > 0 bytes`

**预期结果**：
- 如果RX=7字节 → UART4收发正常
- 如果RX=0字节 → UART4硬件或软件问题

**⚠️ 测试完后务必断开短接！**

---

### 测试2：用电脑串口工具测试传感器

**目的**：验证传感器本身是否工作

**步骤**：
1. 断开传感器与STM32的连接
2. 用USB转TTL模块连接传感器（TX↔RX，RX↔TX，GND↔GND）
3. 打开串口助手（115200, 8N1）
4. 发送 `$0,1,0#`
5. 查看传感器是否有返回

**预期结果**：
- 有返回数据 → 传感器工作正常，问题在STM32接线或配置
- 无返回数据 → 传感器故障或协议不匹配
