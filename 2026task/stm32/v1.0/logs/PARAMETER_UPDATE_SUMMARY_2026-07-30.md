### 🟡 优先级2: IR传感器符号验证

**验证方法**：
```c
// 在调试代码中添加
void VerifyIRSign(void) {
    printf("=== IR传感器符号验证 ===\n");
    printf("将小车放在黑线上，观察lateral_error:\n");
    printf("  向右移动 → 应为负值\n");
    printf("  向左移动 → 应为正值\n\n");
    
    perception_t perception;
    perception_init(&perception);
    
    for (int i = 0; i < 100; i++) {
        uint16_t ir_raw[8];
        if (IrUartSensor_GetAnalog(ir_raw)) {
            ir_array_data_t ir_data;
            ir_data.active_mask = 0xFF;
            for (int j = 0; j < 8; j++) {
                ir_data.values[j] = (float)ir_raw[j];
            }
            
            perception_result_t result;
            perception_update(&perception, &ir_data, 0, &result);
            
            printf("\rLateral Error: %7.3f  (右偏应<0, 左偏应>0)", 
                   result.lateral_error);
            fflush(stdout);
        }
        HAL_Delay(100);
    }
    printf("\n");
}
```

**预期结果**：
- 小车向右偏 → `lateral_error < 0`
- 小车向左偏 → `lateral_error > 0`
- 如果符号反了，需要调整权重数组

## ⚡ 关键提醒

### 编码器配置的重要性

**之前的334配置导致的问题**：
```
实际速度: 0.5 m/s
编码器测量(错误): 0.5 × (334/1560) = 0.107 m/s
速度估计错误: -78.6%

或者反过来：
实际速度: 0.107 m/s  
编码器测量(错误): 0.107 × (1560/334) = 0.5 m/s
速度估计错误: +367%
```

这会导致：
- 车辆认为自己很慢，实际却很快 → 冲出赛道
- 或车辆认为自己很快，实际却很慢 → 无法跟上指令

**所以编码器验证是第一优先级！**
