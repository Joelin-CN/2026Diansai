## 1. 文档说明

### 1.1 目的

本文档提供系统中所有关键参数的完整追溯信息，包括：
- 参数来源（测量/计算/调参/设计）
- 验证状态（已验证/待验证/理论值）
- 跨文件一致性检查
- 变更历史记录

### 1.2 参数类型定义

| 类型 | 名称 | 说明 | 验证方法 |
|-----|------|------|---------|
| **A** | 物理测量参数 | 需要实际测量的硬件参数 | 测量工具 + 实车验证 |
| **B** | 理论计算参数 | 可通过公式推导的参数 | 数学验证 + 实测确认 |
| **C** | 经验调参 | 需要实验调优的控制参数 | 阶跃响应/频率响应测试 |
| **D** | 硬件约束参数 | 由硬件/系统设计决定的参数 | 规格书 + 示波器验证 |

## 2. 参数分类体系

### 2.1 参数来源分类


```
物理层参数 (Type A/B)
├── 机械参数: 轮距、轮半径、传感器位置
├── 电气参数: 编码器PPR、PWM频率、电机参数
└── 传感器参数: IMU scale、编码器方向

控制层参数 (Type C)
├── PID参数: Kp, Ki, Kd
├── 前馈参数: K_accel, K_friction, K_static
└── 滤波参数: filter_alpha, smooth_tau

系统层参数 (Type D)
├── 频率参数: 主循环频率、PID频率
├── 约束参数: 最大速度、最大加速度
└── 硬件参数: PWM ARR、定时器配置
```

#### ENCODER_PPR (编码器分辨率)

| 属性 | 值 |
|-----|---|
| **参数名** | `ENCODER_PPR` |
| **当前值** | 60000 counts/revolution |
| **类型** | B - 理论计算参数（已实测验证） |
| **单位** | counts per revolution |
| **来源** | 理论计算: 500 PPR × 4倍频 × 30减速比 = 60,000 |
| **理论依据** | - 电机编码器线数: 500 PPR（厂商规格书）<br>- 4倍频（AB相正交解码）: 500 × 4 = 2,000 counts/电机转<br>- 减速比: 30:1（齿轮箱规格书）<br>- 编码器安装位置: 电机轴上（减速前） |
| **验证状态** | ✅ 已验证 - 2026-07-30实测 |
| **验证工具** | `motor_speed_test.c` |
| **验证数据** | - 左轮计数: 128,950 counts<br>- 右轮计数: 121,629 counts<br>- 实际转动: 2.2 圈（手动计数）<br>- 实测值: 128,950 / 2.2 = 58,614 counts/圈<br>- 偏差: (60,000 - 58,614) / 60,000 = 2.3% ✅ |
| **偏差分析** | - 手动数圈可能有±0.1圈误差<br>- 减速比可能不完全是30.0:1（制造公差）<br>- 轮胎与地面可能有轻微打滑 |
| **历史变更** | 334 → 1560 → 60000 (2026-07-30确认) |
| **文档引用** | `logs/2026-07-30_encoder_ppr_correction.md`, `logs/PARAMETER_UPDATE_SUMMARY_2026-07-30.md` |
| **一致性要求** | 必须与 `config.c::pulses_per_revolution` 保持一致 |
| **影响分析** | 此参数错误会导致速度估计错误成比例放大，可能导致系统失控 |
| **警告** | 这是最关键的参数之一，更换电机或编码器后必须重新标定 |

#### PID_CONTROL_FREQ_HZ (PID控制频率)

| 属性 | 值 |
|-----|---|
| **参数名** | `PID_CONTROL_FREQ_HZ` |
| **当前值** | 100 Hz |
| **类型** | D - 硬件约束参数（系统设计，已优化） |
| **单位** | Hz |
| **来源** | 系统优化 (2026-07-30) |
| **设计理由** | 匹配执行器响应时间: TB6612电机驱动器响应时间约10ms |

| **影响分析** | - 过高: 浪费CPU，PID来不及看到效果就再次调整<br>- 过低: 控制延迟增加，响应变慢 |
| **警告** | 修改此值需要重新调整PID参数（特别是Ki和Kd） |
