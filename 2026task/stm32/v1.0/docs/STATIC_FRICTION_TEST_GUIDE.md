# 静摩擦补偿参数 FF_K_STATIC 标定指南

## 概述

本文档指导如何使用串口交互式测试程序标定前馈控制的静摩擦补偿参数 `FF_K_STATIC`。

## 测试目的

找到小车从静止启动时克服最大静摩擦力所需的最小 PWM 值，用于运动控制的前馈补偿。

## 准备工作

### 硬件准备
- [x] 小车充满电（电池电压 ≥ 7.4V）
- [x] 放置在**平坦、干燥的测试地面**（与实际比赛环境相同）
- [x] 串口连接（USB转TTL或板载ST-Link）
- [x] 串口调试工具（波特率：115200，8N1）

### 软件准备
1. 已烧录测试程序（`TEST_MODE_STATIC_FRICTION`）
2. 串口工具配置：
   - 波特率：115200
   - 数据位：8
   - 停止位：1
   - 校验位：无
   - 流控：无

## 测试步骤

### Step 1: 启动测试程序

1. 连接串口
2. 复位STM32
3. 观察串口输出：


## 数据分析

### 计算平均值

假设测试结果：
- **左轮**：65, 65, 65, 65, 65 PWM → 平均值 = **65 PWM**
- **右轮**：68, 68, 68, 68, 68 PWM → 平均值 = **68 PWM**

### 添加安全裕度

```
左轮最终值 = 65 × 1.2 = 78 PWM
右轮最终值 = 68 × 1.2 = 81.6 PWM ≈ 82 PWM
```

### 确定 FF_K_STATIC

**策略A（保守，推荐）**：取较大值
```
FF_K_STATIC = max(78, 82) = 82 PWM
```

**策略B（平衡）**：取平均值
```
FF_K_STATIC = (78 + 82) / 2 = 80 PWM
```

**推荐使用策略A**，确保两轮都能可靠启动。

### 修改代码

编辑 `modules/MotionControl/inc/motion_config.h`：

```c
/**
 * @brief 静摩擦补偿 (PWM)
 * ...
 */
#define FF_K_STATIC  82.0f  // 从 80.0f 更新为 82.0f
```

## 注意事项

### 测试环境
- **必须在实际使用的地面上测试**（木地板、瓷砖、赛道等）
- 不同地面的摩擦系数不同，会影响结果
- 测试时小车轮子必须**接触地面**（不要悬空）

### 测试技巧
- 每次测试前确保小车**完全静止**
- 施加PWM后等待**至少2秒**再读取编码器
- 如果编码器计数在 15-25 之间（接近阈值），重复测试确认
- 左右轮可能有制造差异，分别测试更准确

### 常见问题

**Q1: 编码器一直为0，轮子明明在转？**
- 检查编码器连接
- 确认 `Encoder_Poll()` 被周期性调用（测试程序已包含）

**Q2: PWM=50 时轮子就能转，是否正常？**
- 可能是地面摩擦力较小（如光滑瓷砖）
- 这是正常的，按实际测试结果标定即可

**Q3: 左右轮差异很大（>10 PWM），怎么办？**
- 检查轮子是否有异物、磨损
- 检查电机是否正常
- 仍然可以使用较大值作为 FF_K_STATIC

**Q4: 重复测试结果不稳定，有时转有时不转？**
- 说明PWM值在临界点，增加5继续测试
- 确保每次测试前小车完全静止
- 检查电池电量（低电压会影响结果）

## 验证

标定完成后，验证方法：

1. **编译新参数的代码**
2. **切换到循迹模式**（`TEST_MODE_PLAYGROUND_TRACK`）
3. **观察启动表现**：
   - ✓ 小车平滑启动，无延迟
   - ✓ 无明显冲击或抖动
   - ✗ 启动困难 → FF_K_STATIC 偏低，增加10
   - ✗ 启动有冲击 → FF_K_STATIC 偏高，减少10

## 快速参考

### 命令速查表

| 命令 | 功能 | 示例 |
|------|------|------|
| `L <pwm>` | 测试左轮 | `L 65` |
| `R <pwm>` | 测试右轮 | `R 70` |
| `B <pwm>` | 测试双轮 | `B 50` |
| `S` | 停止 | `S` |
| `E` | 读取编码器 | `E` |
| `C` | 清零编码器 | `C` |
| `H` | 帮助 | `H` |

### 标准测试流程（单轮）

```
1. C          (清零)
2. L 50       (施加PWM)
3. 等待2秒
4. E          (读取编码器)
5. S          (停止)
6. 重复步骤1-5，逐步增加PWM直到编码器≥20
7. 找到最小PWM后，重复测试5次验证
```
