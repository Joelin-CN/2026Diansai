# 评估报告 HTML 设计说明

## 目标

将现有 `摆杆升降装置性能评估报告.md` 转换为可直接双击打开的单文件 HTML 技术报告，解决普通 Markdown 查看器无法渲染数学公式的问题。

## 交付物

- 文件：`摆杆升降装置性能评估报告.html`
- 位置：与原 Markdown 报告相同目录
- 使用方式：通过浏览器直接打开，不要求本地 HTTP 服务器

## 内容策略

HTML 完整内嵌 Markdown 报告的正文、表格和公式，不在运行时读取 Markdown 文件。原 Markdown 更新后，HTML 需要同步更新。

## 数学公式

页面通过 CDN 加载 KaTeX CSS、KaTeX 核心脚本和 auto-render 扩展。页面加载完成后自动渲染以下定界符：

- 行内公式：`\(...\)` 和 `$...$`
- 块级公式：`\[...\]` 和 `$$...$$`

KaTeX CDN 加载失败时显示警告，正文和表格仍保持可读，公式显示为 LaTeX 源码。

## 页面结构

- 顶部报告标题和摘要信息
- 关键结论摘要卡片
- 左侧章节目录
- 17 个正文一级章节及其子章节
- 表格横向滚动容器
- 报告日期和方案阶段声明

## 视觉与适配

- 使用适合工程技术报告的中性配色和窄版正文布局
- 桌面端显示固定章节目录
- 小屏幕下隐藏固定目录，正文占满可用宽度
- 表格在窄屏幕上允许横向滚动
- 提供打印样式，打印时隐藏目录和加载警告，并移除不必要的阴影和背景

## 依赖与失败处理

- 唯一外部依赖为 KaTeX CDN
- 不引入前端框架、Markdown 解析器或构建工具
- CDN 失败不阻止正文显示
- JavaScript 只负责 KaTeX 自动渲染和加载失败提示

## 验证

- 检查 HTML 文档结构及闭合标签
- 检查 KaTeX CSS、核心脚本和 auto-render 脚本引用
- 检查 17 个一级章节均已写入
- 检查关键公式、导程表和步进电机专项评估内容存在
- 检查桌面、窄屏和打印 CSS
- 在浏览器中打开并确认公式渲染及目录锚点可用

## 范围外事项

- 不提供离线 KaTeX 资源
- 不提供 Markdown 到 HTML 的自动生成脚本
- 不修改原 Markdown 报告的技术结论
