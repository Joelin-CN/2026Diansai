- [ ] **Step 2: 创建 HTML 文档骨架和样式**

使用 `apply_patch` 创建目标 HTML，文档必须包含：

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>摆杆升降装置性能评估报告</title>
  <link rel="preconnect" href="https://cdn.jsdelivr.net">
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/katex@0.16.11/dist/katex.min.css">
  <script defer src="https://cdn.jsdelivr.net/npm/katex@0.16.11/dist/katex.min.js"></script>
  <script defer src="https://cdn.jsdelivr.net/npm/katex@0.16.11/dist/contrib/auto-render.min.js"></script>
</head>
<body>
  <div id="katex-warning" role="alert" hidden>数学公式组件加载失败，当前显示 LaTeX 源码。请检查网络连接后刷新页面。</div>
  <div class="page-shell">
    <aside class="toc" aria-label="报告目录"></aside>
    <main class="report"></main>
  </div>
</body>
</html>
```

CSS 必须定义以下行为：

- `.page-shell` 在桌面端使用目录加正文双栏布局；
- `.toc` 在桌面端固定于可视区域并支持内部滚动；
- `.report` 使用不超过约 980 px 的正文宽度；
- `.table-wrap` 支持横向滚动；
- `.summary-grid` 展示关键结论卡片；
- `@media (max-width: 900px)` 隐藏固定目录并改为单栏；
- `@media print` 隐藏目录、警告和屏幕装饰，保留清晰正文与表格。

- [ ] **Step 3: 转写报告正文和目录**

把 Markdown 的 17 个一级章节完整转成语义化 HTML：

```html
<section id="section-1">
  <h2>1. 评估目的</h2>
  <!-- 对应正文、列表和表格 -->
</section>
```

目录锚点必须和章节 `id` 一一对应：

```html
<nav>
  <a href="#section-1">1. 评估目的</a>
  <!-- 直到 section-17 -->
</nav>
```

转换规则：

- Markdown 表格转成 `<div class="table-wrap"><table>...</table></div>`；
- 注意事项转成 `<aside class="callout">...</aside>`；
- 行内代码转成 `<code>`；
- 行内公式保留 `\(...\)`；
- 块级公式保留 `\[...\]`；
- 技术数字、公式和结论不得改写；
- 报告顶部增加摘要卡片，显示 `25 cm` 杆长、`<= 5 s`、`75 mm/s`、`8 mm/rev` 四个核心指标。

- [ ] **Step 4: 初始化 KaTeX 与失败提示**

在 `</body>` 前加入：

```html
<script>
  window.addEventListener("load", function () {
    var warning = document.getElementById("katex-warning");
    if (typeof renderMathInElement !== "function") {
      warning.hidden = false;
      return;
    }

    renderMathInElement(document.querySelector(".report"), {
      delimiters: [
        { left: "$$", right: "$$", display: true },
        { left: "\\[", right: "\\]", display: true },
        { left: "\\(", right: "\\)", display: false },
        { left: "$", right: "$", display: false }
      ],
      throwOnError: false,
      ignoredTags: ["script", "noscript", "style", "textarea", "pre", "code"]
    });
  });
</script>
```
