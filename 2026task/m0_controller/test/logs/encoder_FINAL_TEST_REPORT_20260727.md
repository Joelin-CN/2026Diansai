- 解决：交换电机的正负极接线

### 选项B：软件修正（快速但不推荐）

在 `src/encoder.c` 中反转M3和M4的计数：

```c
int32_t Encoder_GetCount(Encoder_Id encoder)
{
    if ((uint8_t)encoder >= (uint8_t)ENCODER_ID_COUNT) return 0;
    
    int32_t count = g_encoderCount[encoder];
    
    // Invert M3 and M4 counts to match motor direction
    if (encoder == ENCODER_M3 || encoder == ENCODER_M4) {
        count = -count;
    }
    
    return count;
}
```

**不推荐原因**：
- 混淆了硬件实际方向
- 后续维护容易出错
- 不符合直觉
