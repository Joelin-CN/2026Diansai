## 发现的问题

### 问题1：M1/M2 和 M3/M4 左右位置互换

**现象：** 用户观察可视化后确认，橙色（M1）和青绿色（M2）标记出现在了右侧，而实车上 M1/M2 在左侧。

**原因：** Part 3 的坐标系重构中对"用户视角左右"与"代码左右"的对应关系理解仍然错误。

**修复：**
- M1/M2（wheel_lf/lr）从 X=+0.075（右侧）→ **X=-0.075（左侧）**
- M3/M4（wheel_rf/rr）从 X=-0.075（左侧）→ **X=+0.075（右侧）**

---

### 问题2：M1/M2 旋转方向反向

**现象：** 位置校正后，M1/M2 旋转时黄色标记向后滚而非向前滚。

**根本原因：** 旋转轴方向与物理位置无关，所有轮子正转应使用相同的轴方向。

| 轮子 | 错误轴 | 修正轴 | 说明 |
|------|--------|--------|------|
| M1 (wheel_lf) | +1 0 0 | **-1 0 0** | 与右侧保持一致 |
| M2 (wheel_lr) | +1 0 0 | **-1 0 0** | 与右侧保持一致 |

**结论：** 对于车头朝 +Y 的差速机器人，所有轮子正ω → 前进对应 axis=(-1,0,0)，与左右位置无关。

---

### 问题3：M3/M4 前后位置互换

**现象：** M3/M4 左右位置正确、旋转方向正确，但 M3 出现在右前、M4 在右后，与实车相反。

**修复：**
- M3（wheel_rf）从 Y=+0.100（前）→ **Y=-0.100（后）**
- M4（wheel_rr）从 Y=-0.100（后）→ **Y=+0.100（前）**

---

## 最终确认的轮子布局

```
         +Y（车头方向）
          ↑
   M1(🟠) │ M4(🟣)   ← 前轮（Y=+0.100）
  -0.075  │ +0.075
          │
   M2(🟢) │ M3(🔵)   ← 后轮（Y=-0.100）
  -0.075  │ +0.075
          │
  ────────+────────→ +X（右侧方向）
        原点
```

|------|--------|-------------|--------|----------|
| M1 | wheel_lf | (-0.075, +0.100) | (-1, 0, 0) | 橙色 🟠 |
| M2 | wheel_lr | (-0.075, -0.100) | (-1, 0, 0) | 青绿 🟢 |
| M3 | wheel_rf | (+0.075, -0.100) | (-1, 0, 0) | 蓝色 🔵 |
| M4 | wheel_rr | (+0.075, +0.100) | (-1, 0, 0) | 紫色 🟣 |

**关键结论：** 所有四个轮子旋转轴均为 `axis=(-1, 0, 0)`，给定正 ω 均向前滚动。
